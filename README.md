# Лабораторная работа №1. Абстрактные структуры данных

## Описание

Консольная СУБД на C++17, реализующая базовый набор абстрактных структур данных
с единым интерфейсом команд, чтением/записью в файл и оценкой сложности операций
в нотации Big-O.

## Задание

1. Реализовать структуры данных с базовым набором операций:
   - **Массив (M):** создание, добавление элемента (по индексу и в конец), получение по индексу, удаление по индексу, замена по индексу, длина, чтение.
   - **Односвязный список (F):** добавление и удаление (4 способа: до/после головы/хвоста), чтение (несколько способов), удаление по значению, поиск по значению.
   - **Двусвязный список (L):** аналогично односвязному.
   - **Стек (S):** push, pop, чтение.
   - **Очередь (Q):** push, pop, чтение.
   - **Дерево (T):** по варианту (1 — красно-чёрное, 2 — АВЛ, 3 — Complete Binary Tree, 4 — Full Binary Tree). Добавление, поиск, удаление с сохранением структуры, чтение. Для вариантов 3–4 вместо удаления — проверка на Full/Complete.

2. Реализовать интерфейс работы со структурами:
   - считывание из файла и запись в файл при изменениях;
   - команды вида `<Буква><Операция>` (первая буква — структура), например `MPUSH`, `FDEL`, `SPOP`, `QPOP`, `TINSERT`;
   - `PRINT` — вывод любой структуры на экран.

3. Обосновать сложность каждой операции в нотации Big-O и составить таблицу в отчёте.

4. Описать достоинства, недостатки и области применения каждой структуры.

5. В отчёте привести контрольный пример с визуальными формами, подтверждающими результаты работы программы.
